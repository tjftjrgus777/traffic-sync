1. 데이터베이스 개요

항목내용
DBMSOracle Autonomous Database (클라우드)
인증Oracle Wallet(mTLS). Spring은 TNS_ADMIN 경로 지정, Flask(예측·뉴스)는 동일 Wallet 공유
접속 계층Spring Data JPA(Hibernate, ddl-auto=update) · Python oracledb
커넥션 풀HikariCP — 최대 10, 최소 유휴 3, 유휴 타임아웃 120초, 최대 수명 30분, keepalive 60초
스키마 관리JPA 엔터티 기준 자동 갱신(PoC). 운영 전환 시 마이그레이션 도구 도입 예정

2. 엔터티 관계 개요 (ERD)

[교통 도메인]
  CROSSROAD (V2X 교차로 마스터)
    1 ─ 1  CROSSROAD_SUPPLEMENTAL_MAPPING   (대표 링크 매핑)
    1 ─ N  CROSSROAD_DIRECTION_LINK         (방향별 진입 링크 매핑, 복합키 CRSRD_ID+DIRECTION_CODE)

[신호 도메인 — 경찰청, INT_NO 체계]
  SIGNAL_CROSSROAD (신호 교차로)
    1 ─ N  SIGNAL_PHASE  (현시구성, 복합키 INT_NO+MAP_NO)
    1 ─ N  SIGNAL_PLAN   (운영계획, 복합키 INT_NO+PLAN_NO+PLAN_IDX_NO)
  ※ CROSSROAD(CRSRD_ID)와 SIGNAL_CROSSROAD(INT_NO)는 식별자 체계가 달라
     좌표 기반 350m 최근접 매칭(애플리케이션 레벨)으로 결합

[TOPIS 도로망]
  TOPIS_ROAD_DIV (도로구분) 1 ─ N TOPIS_ROAD_AXIS (도로축)
  TOPIS_ROAD_AXIS 1 ─ N TOPIS_AXIS_LINK (축 링크)
  TOPIS_AXIS_LINK 1 ─ N TOPIS_LINK_VERTEX (링크 좌표열, 복합키 LINK_ID+SEQ)

[사용자·민원]
  USERS 1 ─ N COMPLAINTS (USER_ID 논리 참조)
  COMPLAINTS 1 ─ N COMPLAINT_PHOTOS (COMPLAINT_ID 논리 참조)

[독립 테이블]
  TRAFFIC_NEWS (뉴스, LINK PK) · TRAFFIC_STATION (교통량 지점) · CCTV3 (CCTV 메타)
주. 관계는 JPA 연관관계 어노테이션 없이 식별자 컬럼으로 유지되는 논리 관계다(조회 성능·적재 단순화 목적). 참조 무결성은 애플리케이션 레벨에서 관리한다(민원 삭제 시 사진 일괄 삭제 등).

3. 테이블 정의서

3.1 CROSSROAD — V2X 교차로 마스터

컬럼타입키설명
CRSRD_IDVARCHAR2PKV2X 교차로 ID
CRSRD_NMVARCHAR2교차로 이름
LAT / LONNUMBER위도·경도. Haversine 반경 검색 대상

3.2 SIGNAL_CROSSROAD — 신호 교차로 (경찰청)

컬럼타입키설명
INT_NOVARCHAR2PK신호 교차로 번호
INT_NMVARCHAR2교차로 이름
REGION_CDVARCHAR2지역 코드(L01=서울)
X_COORD / Y_COORDVARCHAR2경도·위도 — 1e7 스케일 정수 문자열(조회 시 1e7로 나눠 복원)
UPD_DTIMEVARCHAR2원천 갱신 일시

3.3 SIGNAL_PHASE — 현시구성

컬럼타입키설명
INT_NO + MAP_NOVARCHAR2PK(복합)교차로 번호 + 현시 맵 번호
INT_NM, REGION_CDVARCHAR2이름·지역
A_RING_1 ~ A_RING_8VARCHAR2A링(주 방향) 현시별 방향 코드
B_RING_1 ~ B_RING_8VARCHAR2B링(대향 방향) 현시별 방향 코드

3.4 SIGNAL_PLAN — 운영계획

컬럼타입키설명
INT_NO + PLAN_NO + PLAN_IDX_NOVARCHAR2PK(복합)교차로·계획·계획인덱스
OPER_PLAN_HH / OPER_PLAN_MIVARCHAR2운영 시작 시·분 — 현재 시각 기준 활성 계획 선정에 사용
CYCLE_VALNUMBER신호 주기(초). Webster 클램핑 기준
OFFSET_VALNUMBER옵셋(인접 교차로 연동용)
A_RING_1~8 / B_RING_1~8NUMBER현시별 지속 시간(초). null·0은 미정의 현시

3.5 TOPIS 도로망 4종

테이블컬럼 요약
TOPIS_ROAD_DIVROAD_DIV_CD(PK), ROAD_DIV_NM, UPDATED_AT_MS — 도로구분(도시고속 등)
TOPIS_ROAD_AXISAXIS_CD(PK), ROAD_DIV_CD, AXIS_NAME, UPDATED_AT_MS — 도로축
TOPIS_AXIS_LINKLINK_ID(PK), AXIS_CD, AXIS_DIR(상행/하행), LINK_SEQ, UPDATED_AT_MS — 축 구성 링크
TOPIS_LINK_VERTEXLINK_ID+SEQ(PK 복합), GRS80TM_X/Y, LAT, LON, UPDATED_AT_MS — 링크 좌표열(형상)

3.6 CROSSROAD_SUPPLEMENTAL_MAPPING — 교차로 대표 링크 매핑

컬럼타입키설명
CRSRD_IDVARCHAR2PKV2X 교차로 ID
GU_NAMEVARCHAR2자치구명
SPEED_LINK_ID / SPEED_DISTANCE_METERSVARCHAR2/NUMBER속도 조회용 최근접 링크와 거리
RISK_SOURCE_LINK_ID / RISK_LINE_STRING / RISK_DISTANCE_METERSVARCHAR2(4000)/NUMBER위험도 조회용 링크·선형(LineString)·거리
UPDATED_AT_MSNUMBER매핑 생성 시각(epoch ms)

3.7 CROSSROAD_DIRECTION_LINK — 방향별 진입 링크 매핑

컬럼타입키설명
CRSRD_ID + DIRECTION_CODEVARCHAR2PK(복합)교차로 + V2X 방향 코드(nt/et/...)
LINK_IDVARCHAR2해당 방향 진입 링크
DISTANCE_METERS / BEARING_DEGREESNUMBER거리·접근 방위각(스냅 허용 오차 67.5도)
UPDATED_AT_MSNUMBER갱신 시각

3.8 USERS — 사용자

컬럼타입키설명
USER_IDVARCHAR2(50)PK로그인 아이디
PASSWORDVARCHAR2(100)비밀번호(현재 평문 — 해시 적용 예정)
NAME / PHONE / EMAILVARCHAR2이름·전화·이메일(아이디/비밀번호 찾기, 메일 발송)
ROLEVARCHAR2(10)USER(관제사) / ADMIN / CIVIL(민원 시민)
STATUSVARCHAR2(10)PENDING / APPROVED / REJECTED — 승인제 가입
ALERT_EMAILNUMBER병목 경보 메일 수신 동의(1/0)
IS_TEMP_PWNUMBER임시 비밀번호 여부 — 1이면 로그인 시 변경 강제
CREATED_ATTIMESTAMP가입 일시

3.9 COMPLAINTS — 민원

컬럼타입키설명
IDNUMBERPK민원 번호
USER_ID / USER_NAMEVARCHAR2신고자(USERS 논리 참조)
TITLE / CONTENTVARCHAR2(200/2000)제목·내용
CATEGORY / DEPARTMENT / AI_REASONVARCHAR2AI 분류 결과(15개 카테고리·담당과·분류 사유)
LAT / LNG / ADDRESS / GU_NAMENUMBER/VARCHAR2위치. GU_NAME은 주소에서 정규식으로 추출(구별 필터)
PHOTO_URLSVARCHAR2(1000)사진 조회 경로 목록(콤마 구분)
STATUSVARCHAR2(20)접수 / 처리중 / 완료 — 변경 시 신고자 메일 발송

3.10 COMPLAINT_PHOTOS — 민원 사진 (BLOB)

컬럼타입키설명
IDNUMBERPK사진 번호
COMPLAINT_IDNUMBER민원 번호(논리 FK). 민원 삭제 시 일괄 삭제
DATABLOB이미지 바이트(HEIC는 접수 전 JPEG 변환)
MIME_TYPEVARCHAR2(50)Content-Type 보존용

3.11 TRAFFIC_NEWS — 교통 뉴스

컬럼타입키설명

CATEGORY / TITLE / SUMMARYVARCHAR2섹터·제목·요약 1문장
SENTIMENTVARCHAR2(20)혼잡악화 / 교통개선 / 중립
PUB_DATEVARCHAR2(50)발행 일시(정렬 기준)
CLICKBAIT_PROBVARCHAR2(20)낚시성 확률(로지스틱 회귀)
ARTICLE_TYPE / TYPE_PROBVARCHAR2(20)BERT 기사 유형·확률

3.12 TRAFFIC_STATION — 교통량 측정 지점

컬럼타입키설명

4. 설계 결정 사항

결정근거
실시간 신호 상태는 DB 미저장(메모리 캐시)30초 주기 휘발성 데이터로 영속화 가치가 낮고, 화면·AI는 항상 최신 스냅샷만 필요. 이력 적재는 향후 분석 요건 발생 시 도입
좌표 기반 반경 검색을 DB(JPQL Haversine)에서 수행후보 전체를 애플리케이션에 적재하지 않기 위함. acos 입력 클램핑으로 부동소수점 오차 방어
민원 사진 BLOB 저장단일 서버 PoC에서 백업·삭제 일관성 단순화. 규모 확대 시 오브젝트 스토리지 전환 경로 확보(사진 단건 서빙 API 기보유)
뉴스 PK를 기사 URL로 지정수집 파이프라인의 중복 삽입을 DB 제약(IntegrityError)으로 차단
두 교차로 체계(CRSRD_ID/INT_NO) 비통합원천 데이터 식별자 체계가 상이. 좌표 매칭(350m)으로 애플리케이션 레벨 결합, 매칭 거리를 함께 보존해 신뢰도 표시
매핑 테이블의 UPDATED_AT_MS 보존24시간 주기 재생성·최소 재요청 간격(위험도 5분) 판단 기준
