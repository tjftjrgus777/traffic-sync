시스템 개요 — 서비스 전체 구성

TrafficSync는 서울시 실시간 교통·기상·돌발상황 데이터를 수집·통합·분석하고, AI 에이전트가 자연어 질의응답·신호 최적화 제안·뉴스 감성 분석·교통량 예측을 수행하는 지능형 교통 모니터링 플랫폼이다.

검증 방법: 본 v4.0 문서는 Java·Python 소스코드 전체를 직접 읽어 작성하였다. MD 설계 문서와 코드가 다를 경우 코드 기준을 따른다.

  • TrafficScheduler: V2X 신호 전담 폴링
  • SupplementalDataScheduler: 날씨·속도·위험도·링크매핑
  • 뉴스 파이프라인: Flask POST /news/fetch 트리거
로컬+외부 AI 혼용
  • 교통 AI: Ollama 완전 로컬 (데이터 보호)
  • 뉴스 요약: Groq API (외부 — 뉴스 본문만 전송)
  • 민원 분류: Gemini Vision API (사진만 전송)
  • 음성 TTS: Google Cloud TTS (ko-KR-Neural2-C)
  • 3개 Groq API 키 라운드로빈 + 429 자동 전환
비동기 처리 최적화
  • aiohttp: 뉴스 본문 비동기 병렬 수집(Semaphore 20)
  • ThreadPoolExecutor: BERT/KoNLPy 블로킹 오프로드
  • asyncio.Queue: DB writer 단건 즉시 삽입

5.2 뉴스 수집 파이프라인 단계별 상세

① Naver News API 호출 (섹터별 순차, 0.5초 간격)
4개 섹터(서울교통·교통사고·대중교통·날씨교통) 또는 run_all.py 5개 섹터(교통사고·도로혼잡·대중교통·교통정책·스마트교통).
각 섹터별 search_query로 Naver 뉴스 API 호출 → 최대 100건 후보 수집.
헤더: X-Naver-Client-Id / X-Naver-Client-Secret (환경변수 .env)
② 뉴스 본문 비동기 수집 (aiohttp, Semaphore=20)
각 기사 URL에서 #dic_area, #newsct_article, #articeBody CSS 선택자로 본문 추출.
타임아웃 5초, 실패 시 RSS description 폴백.
③ 관련도 필터 (KoNLPy Okt 형태소 분석)
공통 제외 단어(EXCLUDE_WORDS: 정치·검찰·부동산 등)·제목 제외 단어(TITLE_EXCLUDE_WORDS: 증시·코스피 등) 필터.
섹터별 keywords 리스트로 제목 직접 포함 또는 KoNLPy 명사 중 1개 이상 매칭 여부 확인.
KoNLPy는 스레드 비안전 → threading.Lock + ThreadPoolExecutor 오프로드.
④ TF-IDF + 로지스틱 회귀 — 과장성(클릭베이트) 점수
clickbait_model.joblib + tfidf_vectorizer.joblib 로드.
제목 + 본문을 벡터화 → 로지스틱 회귀 예측 → clickbait_prob (0~100%) 계산.
TRAFFIC_NEWS 테이블에 CLICKBAIT_PROB로 저장.
⑤ BERT 기사 유형 분류 (ThreadPoolExecutor 오프로드)
모델: model.pt (kykim/bert-kor-base 파인튜닝, 4분류 헤드 Linear(768→4)).
본문을 최대 100자 청크로 분리 → 각 청크 128토큰 tokenize → BERT 추론 → Softmax → 가장 많은 레이블 투표.
결과: 사실형 / 예측형 / 대화형 / 추론형 + 신뢰도(%).
CUDA 사용 가능 시 GPU, 없으면 CPU 자동 선택.
⑥ Groq API — 1문장 요약 + 감성 분석 (비동기, Semaphore=5)
모델: llama-3.1-8b-instant (Groq 외부 API). 3개 API 키 라운드로빈, 429 시 자동 다음 키 전환 (asyncio.sleep 1s).
시스템 프롬프트로 JSON 응답 강제: {"summary": "…", "sentiment": "혼잡악화|교통개선|중립"}.
본문 최대 800자 전송.
⑦ asyncio.Queue → Oracle DB 단건 즉시 삽입
DB writer는 별도 ThreadPoolExecutor(max_workers=1)로 단일 스레드 순차 삽입.
중복 링크(PK 충돌) → IntegrityError 무시·건너뜀.
테이블: TRAFFIC_NEWS (link·category·title·summary·sentiment·pub_date·clickbait_prob·article_type·type_prob).
