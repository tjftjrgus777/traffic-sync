시스템 개요 — 서버 구성

TrafficSync는 4개의 독립 서버로 구성되며, 프론트엔드(React :5173)가 이를 소비한다. 서버 간 통신은 HTTP REST이며, AI 에이전트는 내부적으로 MCP(stdio) 프로토콜로 Spring Boot API를 도구로 호출한다.

:8080
Spring Boot 3 — 메인 백엔드
JWT 인증, Oracle DB, V2X/TOPIS/KMA 공공 API 수집, WebSocket 실시간 브로드캐스트. 모든 비즈니스 로직의 중심.
:8001
Python FastAPI — AI Agent (LangGraph ReAct)
Ollama qwen3:30b-a3b + MCP 9개 도구. SSE 스트리밍으로 ReAct 루프 단계를 실시간 전달.
:5002
Flask — XGBoost 교통량 예측 서버
xgboost_traffic_model.joblib 로드. 지점 ID → Oracle TRAFFIC_STATION 조회 → 오늘 00~23시 24개 시간대 상·하행 예측값 반환.
:5001
Flask — News 뉴스 수집·감성 분석 서버
Naver RSS 4개 카테고리 크롤링 → BERT 키워드 검증 → Groq LLM(3-키 로테이션) 요약·감성 분석 → Oracle TRAFFIC_NEWS 저장.
:8002
Flask — civil_flask_server 민원 분류·자동 답변 서버 v1.1 신규
Gemini Vision API로 사진 기반 민원 카테고리 자동 분류 + 담당 부서 매핑 반환. HEIC/HEIF 자동 변환. Gemini 모델 폴백 체인(2.5-flash → 2.0-flash → lite).

2.1인증 / 사용자 관리 — /api/auth

POST /api/auth/login 로그인 — 사용자 정보 반환 (토큰 없음)

Request Body

{ "userId": "hong123", "password": "1234" }

Response 200

{ "success": true, "userId": "hong123", "name": "홍길동", "role": "ACTIVE", // PENDING | ACTIVE | ADMIN "isTempPw": false, // 임시 비밀번호 여부 "email": "hong@example.com" }
JWT 없음: 토큰을 발급하지 않는다. 프론트는 userId·role을 로컬스토리지에 저장하고 관리자 페이지 진입 시 role 값으로만 분기한다. role이 PENDING이면 승인 대기 안내 화면 표시.
POST /api/auth/register 회원가입 (PENDING 상태로 등록)

Request Body — UserEntity 필드

{ "userId": "hong123", "password": "1234", // BCrypt 해싱 후 저장 "name": "홍길동", "phone": "010-1234-5678", "email": "hong@example.com" }

Response 200

{ "success": true, "message": "가입 완료" }
GET /api/auth/find-id?name={name}&phone={phone} 아이디 찾기

Query Parameters

파라미터타입필수설명
nameStringY사용자 이름
phoneStringY휴대폰 번호

Response 200

{ "userId": "ho****3" } // 마스킹 처리됨
POST /api/auth/find-pw 비밀번호 찾기 — 임시 비밀번호 Gmail 발송

Request Body

{ "userId": "hong123", "email": "hong@example.com" }

Response 200

{ "success": true, "message": "임시 비밀번호가 이메일로 발송되었습니다." }
POST /api/auth/change-pw 비밀번호 변경 (마이페이지)

Request Body

{ "userId": "hong123", "currentPassword": "old1234", "newPassword": "new5678" }

Response 200

{ "success": true, "message": "비밀번호가 변경되었습니다." }
POST /api/auth/alert 이메일 알림 수신 토글 (마이페이지)

Request Body

{ "userId": "hong123", "alertEmail": 1 // 1=수신, 0=거부 }

Response 200

{ "success": true }

관리자 전용 API (role=ADMIN — 프론트 role 체크, 서버 측 강제 없음)

메서드경로설명응답
GET /api/auth/admin/users 전체 사용자 목록 조회 List<UserEntity>
POST /api/auth/admin/approve/{userId} 가입 승인 (PENDING → ACTIVE) { success, message }
POST /api/auth/admin/reject/{userId} 가입 거절 (PENDING → REJECTED) { success, message }
GET /api/auth/alert-emails 알림 수신 동의 이메일 목록 (병목 이메일 발송용) List<String>

3.6SSE 이벤트 포맷

스트리밍 엔드포인트는 모두 동일한 이벤트 스키마를 사용한다.

data: { "type": "<이벤트타입>", "content": "...", ... }\n\n
type언제 발생추가 필드
thought LLM <think> 블록 파싱 (qwen3 내부 추론) content: 추론 텍스트 (최대 200자)
action MCP 도구 호출 직전 tool: 도구 이름, label: 한글 레이블, args: "k=v, ..." 문자열
observation 도구 실행 결과 수신 후 content: 결과 요약 (JSON 키 나열 또는 "[N개 항목]")
answer LLM 최종 답변 (도구 호출 없는 마지막 응답) content: 최종 답변 텍스트
done 스트림 종료 없음
error 예외 발생 content: 에러 메시지

SSE 스트림 예시

data: {"type":"action","tool":"get_traffic_data","label":"교차로 실시간 데이터 조회","args":"crossroad_id=1007"} data: {"type":"observation","content":"{ crsrdNm, speedKph, congestion, signals ... }"} data: {"type":"answer","content":"잠실역사거리는 현재 서행 상태입니다. 속도 24.5km/h..."} data: {"type":"done"}

Flask XGBoost 예측 서버 (:5002)

도로교통공단 교통량 조사 이력 데이터로 학습한 XGBoost 모델(xgboost_traffic_model.joblib)을 서빙한다. 지점 ID를 받아 Oracle TRAFFIC_STATION에서 위경도를 조회하고 당일 00~23시 24시간 상·하행 교통량을 예측한다.

POST /predict_traffic 24시간 교통량 예측 — 상행·하행 각 24개 값

Request Body

{ "Station_Number": 10 } // Oracle TRAFFIC_STATION.STATION_ID

Response 200

{ "success": true, "station_number": 10, "station_name": "잠실IC", "forecast": [ { "time": "00:00", "direction_0": 1200, "direction_1": 980 }, { "time": "01:00", "direction_0": 890, "direction_1": 750 }, // ... 총 24개 항목 (00:00 ~ 23:00) ] }
direction_0 = 상행(Up), direction_1 = 하행(Down). 단위: 대/시 (vehicles per hour).
