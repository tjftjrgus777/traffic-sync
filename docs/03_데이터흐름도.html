8. 신호계획-실시간 데이터 결합 (좌표 조인)

경찰청 신호 교차로(INT_NO 체계)와 V2X 교차로(CRSRD_ID 체계)는 식별자 체계가 달라 직접 조인할 수 없다. 시뮬레이션 컨텍스트 생성 시 신호 교차로 좌표에서 Haversine 거리로 350m 이내 최근접 V2X 캐시 교차로를 찾아 실시간 속도·혼잡도를 결합하며, 350m를 초과하면 실시간 데이터 없음으로 명시한다.

주. 서로 다른 공공데이터의 키 불일치를 공간(좌표) 매칭으로 해소한 사례로, 매칭 거리도 응답에 포함하여 신뢰도를 표시한다.
