2. 화면별 기능 명세

2.1 로그인 (FN-LOGIN)

ID기능명세
FN-LOGIN-01로그인아이디·비밀번호 검증. CIVIL 계정·승인대기(PENDING)·거절(REJECTED)은 각각 별도 메시지로 차단. 성공 시 사용자 정보를 로컬 저장
FN-LOGIN-02회원가입아이디 중복 확인 후 PENDING 상태로 생성. 승인 전 로그인 불가 안내
FN-LOGIN-03아이디 찾기이름+전화번호 일치 시 아이디 뒤 3자리 마스킹하여 반환
FN-LOGIN-04비밀번호 찾기아이디+이메일 일치 시 임시 비밀번호(8자리) 발급·메일 발송. 임시 비밀번호 로그인 시 마이페이지로 강제 이동
FN-LOGIN-05관리자 승인관리자 로그인 시 유저 목록 조회, 승인/거절 처리
FN-LOGIN-06로그인 브리핑성공 직후 현재 위치 날씨와 미처리 민원 건수를 병렬 조회하여 브리핑 카드+음성 안내

2.2 메인 대시보드 (FN-MAIN)

ID기능명세
FN-MAIN-01구 선택·수집SVG 지도에서 구 클릭 → /api/fetch-area(반경 2.5km) 호출 → 수집 완료 시 교차로 수 표시. 수집 중 중복 요청은 차단 메시지
FN-MAIN-02실시간 KPIWebSocket 수신 데이터 기준 평균 속도·혼잡 분포·평균 대기 등 카드 표시
FN-MAIN-03위험 순위위험지수·등급 기준 정렬 목록, 관심 교차로 워치리스트
FN-MAIN-04교통량 예측 차트지점 선택 → /api/forecast/station/{id} → 상행/하행 24시간 예측 차트
FN-MAIN-05구 AI 리포트구 브리핑 수락 시 /api/agent/district-report/stream SSE로 단계·결과 표시 및 음성 안내
FN-MAIN-06병목 경보 메일버튼 클릭 시 현재 구의 병목 리포트 생성 후 로그인 사용자 메일로 발송

2.3 실시간 지도 (FN-MAP)

ID기능명세
FN-MAP-01교차로 표시줌 레벨에 따라 개별 오버레이/클러스터 전환. 혼잡도 색상 규칙: 15km/h 미만 적색, 25km/h 미만 황색, 이상 녹색
FN-MAP-02신호 패널선택 교차로의 방향별(북·동·남·서) 직진/좌회전/보행 신호와 잔여시간 표시. 잔여시간은 수신 시점 이후 경과를 0.1초 단위로 차감하여 보간
FN-MAP-03AI 챗봇SSE 기반 질의응답. 도구 호출 단계 시각화, 120초 타임아웃 시 최대 2회 자동 재시도, 정지 버튼으로 생성 중단
FN-MAP-04멀티에이전트 시각화주변 분석 시 중심-워커 교차로를 지도에 연결선·파동으로 표시하고, 채팅창에 워커 분석·토론 3라운드·종합을 실시간 렌더링
FN-MAP-05CCTV·민원 마커CCTV 마커 클릭 시 영상 모달, 민원 마커 클릭 시 민원 팝업 표시
FN-MAP-06로드뷰교차로 위치 카카오 로드뷰 모달 제공

2.4 신호 시뮬레이션 (FN-SIM)

ID기능명세
FN-SIM-013D 지도VWorld(Cesium) 3D 지도에 신호 교차로 표시. 구 중심으로 카메라 이동(고도 1200m, 피치 −45도)
FN-SIM-02신호계획 재현교차로 선택 시 현재 시각 기준 활성 운영계획·현시·경과 시간을 계산해 현시 진행 바·방향 표시
FN-SIM-03경로 지정·차량 애니메이션출발·경유·도착 지정 → 구간별 링크 매칭 → 차량 이동 애니메이션과 구간 속도 표시
FN-SIM-04병목 자동 분석경로 확정 시 15km/h 미만 구간 추출 → 신호계획 동봉하여 AI 분석 요청 → Webster 조정안 수신
FN-SIM-05조정안 적용교차로별 조정안을 슬라이더에 반영, 관제사 승인 시 시뮬레이션에 적용. 조정 사유 설명문 표시
FN-SIM-06시뮬레이션 챗봇수동 질문 지원. 관제사 수동 조정값과 원계획 비교 분석, Webster 상세 리포트 메일 요청 가능
FN-SIM-07진입 가드선택 구의 데이터 수집(fetch-area)이 완료되기 전에는 진입을 차단하고 안내 문구 표시

2.5 CCTV 관제 (FN-CCTV)

ID기능명세
FN-CCTV-01CCTV 목록전체/반경 조회(/api/cctv, /api/cctv/area). 스트림 매핑 여부 표시
FN-CCTV-02영상 표시UTIC 공개 스트림 페이지를 임베드하여 채널별 영상 표시

2.6 교통 뉴스 (FN-NEWS)

ID기능명세
FN-NEWS-01뉴스 목록/api/news/latest?limit=200 1회 조회 후 클라이언트에서 카테고리·검색어 필터링
FN-NEWS-02감성 표시기사별 감성(혼잡악화/교통개선/중립) 라벨과 집계 표시
FN-NEWS-03신뢰도 표시낚시성 확률(clickbait_prob)·기사 유형(article_type) 표시

2.7 민원 관리 (FN-CMP)

ID기능명세
FN-CMP-01목록·필터전체 또는 구 단위(guName) 민원 목록 조회
FN-CMP-02상태 변경접수/처리중/완료 변경 시 신고자 이메일로 처리 상태 자동 발송
FN-CMP-03사진 조회DB BLOB로 저장된 사진을 /api/complaints/photos/{id}로 표시
FN-CMP-04삭제민원 삭제 시 연관 사진 일괄 삭제
FN-CMP-05실시간 알림신규 민원 감지 시 관제 화면 상단 배너 알림(음성 음소거 연동)

2.8 민원 시민 화면 (FN-CIV)

ID기능명세
FN-CIV-01민원 가입·로그인CIVIL 역할로 즉시 승인 가입. 일반 계정과 분리된 로그인
FN-CIV-02위치 선택현재 위치(geolocation) 또는 지도 클릭으로 민원 위치·주소 지정
FN-CIV-03사진 AI 분류사진 업로드 시 분류 서버(:8002) 호출 → 카테고리·담당과·사유 표시. HEIC는 JPEG 변환본 미리보기
FN-CIV-04접수분류 결과를 포함해 multipart로 접수. 접수증(카테고리·담당과) 표시
FN-CIV-05날씨 브리핑위치 기반 현재 기온·상태(맑음/흐림/비) 표시

2.9 마이페이지 (FN-MY)

ID기능명세
FN-MY-01비밀번호 변경현재 비밀번호 확인 후 변경. 임시 비밀번호 플래그 해제
FN-MY-02알림 수신 토글병목 경보 메일 수신 여부(alertEmail) 설정

2.10 공통 — 음성 어시스턴트 (FN-VOICE)

ID기능명세
FN-VOICE-01호출더블 클랩(700ms 내 2회, 볼륨 0.22·급등량 0.15 이중 조건) 또는 플로팅 버튼
FN-VOICE-02명령 처리STT → 의도 분류(/api/nav/intent) → 페이지 이동·구 선택·마이페이지·로그아웃. 미해당 시 챗봇 스트리밍으로 폴백
FN-VOICE-03음성 출력Google Cloud TTS(ko-KR-Neural2-C). 도구 호출 시 진행 안내 음성 포함
FN-VOICE-04이동 차단AI 분석 진행 중 페이지 이동 시도 시 차단 토스트 표시
FN-VOICE-05구 브리핑 제안구 선택 시 브리핑 시작 확인 팝업 → 수락 시 구 리포트 스트리밍+음성

3. 공통 처리 규칙

항목규칙
혼잡도 기준속도 15km/h 미만 정체, 25km/h 미만 서행, 이상 원활. 속도 부재 시 적색 평균 잔여시간으로 보조 판정(60초 초과 혼잡, 30초 초과 서행)
병목 기준15km/h 이하. 화면 표시·AI 분석·메일 경보 전 영역 동일 적용
데이터 부재 표기더미 값을 생성하지 않고 "미수집(stale)"으로 명시
AI 수치 처리신호 조정 수치는 코드 계산값만 사용. LLM 응답의 수치 변경 금지 지시 및 JSON 검증·수리 적용
메일 발송전 기능 공통으로 Spring 단일 창구(/api/email/send) 사용
WebSocket 재연결연결 종료 시 3초 후 자동 재연결, 연결 직후 REST로 현재 캐시 선로딩
